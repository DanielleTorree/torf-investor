# Torf Investor

Projeto de wireframe para uma aplicação de gerenciamento de investimentos.  
O objetivo é oferecer ao usuário uma visão clara e organizada de sua carteira,  
permitindo cadastrar, editar e excluir ativos de forma simples.

---

## 🎓 Contexto Acadêmico

Este projeto foi desenvolvido como parte da **Pós-Graduação**  
na disciplina **Gestão Ágil de Projetos e Produtos**. 

---

## 📌 Telas do Wireframe

- **Login**
- **Cadastro**
- **Minha Conta**
- **Dashboard**
- **Cadastrar Investimento (Modal)**
- **Editar Investimento (Modal)**
- **Excluir Investimento (Modal)**

---

## 🚀 Tecnologias Utilizadas

- **Miro** para construção do MVP Canvas (utilizando a metodologia Lean Inception)
- **Jira** para construção do backlog
- **Figma** para construção do wireframe

---

## 📖 Objetivo

Este projeto é apenas um protótipo visual,  
servindo como base para o desenvolvimento de uma futura aplicação web.
